# Imagens de apresentação do EyeBridge

- `ilustracao-projeto.png`: ilustração conceitual gerada por IA com o gerador de imagens integrado. Não é fotografia do protótipo; os ícones na tela são ilustrativos.
- `interface-pagina-1.png`: imagem renderizada pelo HUD real do aplicativo, com observações simuladas e perfil de demonstração. Mostra a seleção de Comida.

Os números de telemetria nas capturas de demonstração não constituem benchmark.
As capturas não usam rosto, vídeo ou calibração pessoal. O código de execução não foi alterado para produzi-las.

## Prompt da ilustração

Create one polished wide 16:9 editorial illustration for the GitHub README of EyeBridge, an academic assistive communication prototype using eye tracking. Clearly stylized isometric vector-like digital illustration, NOT a photograph, no photorealism. Pale off-white background, deep charcoal navy, teal accent and restrained amber, generous negative space, crisp clean shapes. Scene: an adult seated comfortably facing an ordinary desktop monitor, a small USB webcam attached to the top center of monitor, a green Raspberry Pi 5 style single-board computer on the desk linked visibly by USB cable to the webcam and video cable to the monitor. Monitor displays exactly four large communication cards in a single horizontal row, one teal highlighted with a circular gaze cursor. No body-worn sensors, no laser, no goggles, no medical machinery, no external buzzer/relay/LED props. A subtle dotted teal gaze line from eyes to monitor. Simple inclusive human depiction, neutral and respectful, no disability stereotype. Title top left exactly 'EyeBridge'. Subtitle exactly 'Comunicação pelo olhar'. Small discreet footer exactly 'Ilustração conceitual'. Do not add technical specs, performance claims, other captions or logos. Prioritize the understandable relationship person -> webcam -> Raspberry Pi -> visual choices, aesthetically coherent and professional rather than busy infographic.
